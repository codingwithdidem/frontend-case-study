# beije. Frontend Case Study

A replica of the beije. "Paketini Oluştur" (Custom Delivery) experience, built with Next.js (Pages Router), TypeScript, Material-UI, and Redux Toolkit.

## Getting Started

First, install dependencies and run the development server using `pnpm`:

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000/custom-packet](http://localhost:3000/custom-packet) with your browser to see the result.

## Running Tests

This project uses Playwright for End-to-End testing. To run the test suite:

```bash
pnpm test
```
